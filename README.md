# Monday Briefs

A prospect-facing page for an automated client-intelligence service: every client gets a personal briefing every Monday (a designed brief, a short podcast, an email and a private portal), and nobody on the firm's team writes it.

Single static page: `index.html`, `favicon.svg`, `og.png`. No build step. Deployed on Vercel.

All firms, clients, headlines and dates on the page are fictional sample content. Timings quoted were measured on the production engine.
